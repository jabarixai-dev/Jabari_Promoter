Jabari Media — Draft Delete v1

Replace the existing admin.js in your Jabari Media website/admin files with this admin.js.

What it adds:
- Drafts and review articles now show a Delete button.
- Published articles do not show Delete.
- Delete asks for confirmation and then removes only draft/review rows.
- If the deleted draft is currently open in the editor, the editor resets.
- No Render environment variables or bot.js changes are required.
